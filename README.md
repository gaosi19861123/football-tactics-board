# サッカー戦術ボード（小学生8人制）

小学生8人制サッカー向けの戦術ボード。各コマが選手を表し、ドラッグで動かして戦術シミュレーションができます。純粋な静的サイト（HTML/CSS/JSのみ、サーバー不要）。

## 主な機能

- ⚽ 8人制ピッチ + 両チーム各8名の駒（マウス/タッチでドラッグ移動）
- 📋 6種のフォーメーション切替（自チーム・相手チーム個別）
- 🎬 戦術シミュレーション（キーフレーム記録・再生・タイムライン・ループ・動きの軌跡表示）
- ➡️ 跑位矢印の描画（クリックで1本ずつ削除）
- 👁 選手の一人称視点（擬似3D・視線方向を調整可・視野コーン表示・カメラ追従）
- 🎯 記憶ゲーム（一人称視点を制限時間だけ見て、全員の位置を盤面で再現 → 誤差から採点）
- 🔒 簡易ログイン

## 記憶ゲーム

実際の試合で必要な「首を振って周りを把握する」力を鍛えるモードです。

1. 難易度、復元する対象、採点方法、視点の選手を選んでスタート

   難易度は「見られる秒数」と「出場人数」の両方を変えます。人数が少ないほど覚える対象が減るので、まずは簡単から。

   | 難易度 | 観察時間 | 出場人数 | 復元する対象(全員の場合) |
   |---|---|---|---|
   | 簡単 | 10秒 | 3対3 | 5人 |
   | 普通 | 8秒 | 5対5 | 9人 |
   | 難しい | 5秒 | 7対7 | 13人 |
   | 地獄 | 3秒 | 8対8 | 15人 |

   出題は「試合の場面」から自動生成されます（自陣ビルドアップ / 中盤の攻防 / 相手陣での崩し / サイド攻撃・クロス / カウンター）。ボールの位置を起点に、攻撃側は押し上げて幅を取り、守備側はボールとゴールの間に縦横コンパクトなブロックを作り、1人がボールに寄せる、という実際のサッカーの原則どおりに配置します。攻撃側は相手の最終ラインを越えない（オフサイドポジションに立たない）ようにしています。「今の配置で出題」を選べば、コーチが自分で並べた場面をそのまま問題にできます。
2. 全画面の一人称視点が制限時間だけ表示されます。視野は80°なので、ドラッグやボタンで見回して覚えます
3. 時間切れで盤面に切り替わり、駒が中央のトレイに並びます。盤面をタップすると「次の駒」が置かれ、置いた駒はドラッグで微調整できます
4. 「答え合わせ」で正解の位置がゴースト表示され、誤差（m）から採点されます

採点は **2m以内のズレは誤差なし**として満点。それを超えた分だけを誤差として、1 人あたり `100 × (1 − (誤差m − 2) ÷ 12)` で計算します（14m以上で0点）。つまり 2m→100点 / 5m→75点 / 8m→50点。その平均が総合スコアで、S(90+) / A(75+) / B(60+) / C(40+) / D のランクが付きます。ベストスコアは難易度・対象・採点方法ごとにブラウザに保存されます。

### 採点方法

| | 内容 |
|---|---|
| 位置だけ合えばOK（既定） | 背番号は不問。チームごとに合計点が最大になる「解答↔正解位置」の対応を総当たりで探して採点します（1チーム最大8人なので 8!=40320 通り）。赤は赤、青は青としか対応しないので、敵味方を取り違えると減点されます |
| 背番号も合わせる | 自2 は自2 の位置に置く必要があります。番号まで覚える上級者向け |

配置の形を覚える練習が目的なら「位置だけ」、誰がどこにいたかまで覚える練習なら「背番号も」を選んでください。

## 使い方

`index.html` をブラウザで開くだけ。ローカルサーバーで動かす場合:

```bash
python3 -m http.server 8777
```

その後 http://localhost:8777 を開く。

## ホスティング

静的サイトなので Netlify / GitHub Pages / Cloudflare Pages などに無料で公開できます。

## 構成

| ファイル | 役割 |
|----------|------|
| `index.html` | ページ構造 |
| `style.css` | スタイル |
| `app.js` | 全ロジック（描画・ドラッグ・シミュレーション・一人称視点・ログイン） |

## 注意

ログインはブラウザ側の簡易ロックです（認証情報がソースに含まれるため本格的なアクセス制限にはなりません）。厳密に守る場合はホスト側のパスワード保護（Netlify / Cloudflare Access 等）やバックエンド認証を利用してください。
